## Case principal

### ProFlow — SaaS para freelancers

[![Produção](https://img.shields.io/badge/PRODUÇÃO-ONLINE-00C853?style=flat-square)](https://www.proflow.pro/)
[![Código](https://img.shields.io/badge/CÓDIGO-GITHUB-181717?style=flat-square&logo=github)](https://github.com/LeonardoRFragoso/ProFlow)

O **ProFlow** centraliza projetos, propostas, clientes, pagamentos e recursos de IA em uma plataforma voltada à operação de freelancers.

**Problema**

Freelancers normalmente administram propostas, entregas, comunicação e pagamentos em ferramentas separadas, aumentando o trabalho manual e reduzindo a visibilidade do projeto.

**Solução**

Uma plataforma SaaS que reúne o fluxo comercial e operacional, oferece apoio de IA para propostas e precificação e integra pagamentos ao processo de execução.

**Arquitetura**

| Camada | Tecnologias |
|---|---|
| Interface | Vue.js |
| API e tempo real | Django REST Framework · Channels · WebSockets |
| Dados e processamento | PostgreSQL · Redis · Celery |
| Integrações | OpenAI · Mercado Pago · OAuth |

**Decisões de engenharia**

- Autenticação JWT com rotação de tokens e OAuth com Google e GitHub
- Processamento assíncrono com Celery e Redis
- Atualizações em tempo real com Django Channels e WebSockets
- Webhooks de pagamento com idempotência e validação
- Rate limiting, documentação OpenAPI/Swagger e testes automatizados
- Deploy separado entre backend e frontend

**Stack:** `Python` · `Django` · `DRF` · `Vue.js` · `PostgreSQL` · `Redis` · `Celery` · `OpenAI` · `Mercado Pago`
